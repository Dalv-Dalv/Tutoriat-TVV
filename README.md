## Important! 

Uneori discutăm aspecte teoretice importante pe care nu le codăm, motiv pentru care vă invităm să veniți **fizic** la tutoriat.

Pentru a vizualiza corect fișierele HTML și pentru a face funcțional codul de **JavaScript**, trebuie să rulați un **live server**.

### Instrucțiuni
- Deschideți terminalul în acest Repository
- Rulați comanda `python3 -m http.server 8000` pentru a lansa un server local pe portul 8000, folosind **Python**.
- Accesați `localhost:8000`.
- Pe pagina principală ar trebui să găsiți o listă cu toate tutorialele.

## Tutoriate

- **Săptămâna 1**
    - Prezentarea tutoriatului
    - Concepte basic de HTML
- **[Săptămâna 2](/S1)**
    - O structură simplă pentru directorul principal al site-ului
    - Noțiuni simple de HTML și CSS
        - Asocierea unui fișier CSS cu unul HTML, folosind `<link>`
        - Cele 6 dimensiuni pentru headlines - `<h1> ... <h6>`
        - Semantică: `<header>, <div>, <span>, <br>, etc. `
        - Butoane, jump prin href=ID la alte elemente cu un ID
- **Săptămâna 3**
    - Selectori în CSS
    - [CSS Diner - Exerciții de CSS cu selectori](https://flukeout.github.io/)
- **Săptămâna 4**
    - Feedback pe proiecte
    - CSS Battle
- **[Săptămâna 5](/S5)**
    - Lucrul cu fișiere **JSON**
        - Funcții **await** în funcții **async**
        - **fetch()**
    - Folosirea rezultatului din fetch()
        - Crearea elementelor DOM prin iterarea rezultatului, folosind **for**
        - Metode pentru liste: **.map**, **.forEach**
    - Atribute custom
    - Event listeners (**onclick**)
- **[Săptămâna 6](/S6)**
    - Site-uri cu mai multe pagini
    - Meniu burger
    - Animații
- **[Săptămâna 7](/S7)**
    - Lucrul cu grid / flex
    - [Flexboxfroggy - CSS și flexbox](https://flexboxfroggy.com/)
    - Galerie UI-Friendly de carduri
- **Săptămâna 8**
    - Tips & Tricks pentru proiecte
    - [CSS Tricks - CSS și flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/)
- **[Săptămâna 9](/S9)**
    - Mai mult flex / grid
    - Utilizarea `property` în CSS
    - Gradient cu JS folosind `property`
- **Săptămâna 10**
    - Despre AJAX și fetch()
    - POST și GET
    - Funcții await și async
    - LAN prin live server
    - Event listeners
    - Event propagation
